# FNF → osu!mania

Веб-конвертер чартов FNF-игр в мапсеты **osu!mania 4K–18K**. Работает на телефоне и на ПК, сервер не нужен.

**Открыть онлайн (основная версия):** https://fnf2osu-converter.pages.dev

**Репозиторий:** https://github.com/anton4ik837-eng/fnf2osu-mania

**Зеркало на GitHub Pages:** https://anton4ik837-eng.github.io/fnf2osu-mania/ — там же доступны прототипы из `lab/`:
- https://anton4ik837-eng.github.io/fnf2osu-mania/lab/video2chart.html
- https://anton4ik837-eng.github.io/fnf2osu-mania/lab/audio-search.html

Проект задеплоен на Cloudflare Pages (Direct Upload, аккаунт `afcaa10b...`). При изменении файлов нужно заново собрать ZIP из `index.html`, `app.js`, `importer.js`, `lame.min.js`, `remotezip.js` и загрузить новую версию в проект `fnf2osu-converter` → Deployments → Create new deployment.

Импорт по ссылке использует маленький Workers-прокси `fnf2osu-fetch` (код в `worker.js`): он нужен только потому, что `gamebanana.com/dl/...` не отдаёт файлы с CORS. Секретов и биндингов у воркера нет.

## Файлы

- `index.html` — интерфейс (открой его в браузере)
- `app.js` — логика разбора чарта, генерации `.osu` и сборки `.osz`
- `importer.js` — импорт по ссылке: GameBanana / GitHub / ZIP, поиск чартов и аудио, прогресс и отмена
- `remotezip.js` — чтение больших ZIP по HTTP Range прямо с CDN GameBanana (не качаем 500 МБ целиком)
- `lame.min.js` — MP3-кодек (вендоренный lamejs), чтобы микшер не раздувал аудио в WAV
- `worker.js` — код CORS-прокси для Cloudflare Workers (задеплоен как `fnf2osu-fetch`)
- `sample-chart.json`, `sample-audio.wav`, `testmod.zip` — тестовые файлы
- `serve.ps1` — локальный HTTP-сервер на `http://localhost:8765/` (только для разработки)
- `test.js` — проверка логики в Node (если он установлен)

## Как пользоваться

1. Открой `index.html` (можно просто двойным щелчком — сервер не нужен).
2. Выбери `.json` чарт(ы) и аудио `.mp3` / `.ogg` / `.wav` (можно перетащить).
   - Несколько `.json` за раз → один `.osz` с несколькими сложностями (имя файла становится названием сложности).
   - Альтернативы: вставить JSON в поле или загрузить по ссылке.
3. Заполни Artist / Title / Creator / сложность, при желании HP/OD.
4. Нажми **«Собрать .osz»** и открой полученный файл в osu!.

### Импорт по ссылке (главный сценарий)

Вставь ссылку на мод и нажми **«Найти чарты по ссылке»** — инструмент сам скачает архив, распакует его, найдёт чарты и аудио и покажет список песен.

Поддерживается:
- **GameBanana**: `https://gamebanana.com/mods/<id>` и прямые `gamebanana.com/dl/<id>`. Если у мода несколько файлов — появится список, выбираешь нужный архив.
- **GitHub**: репозиторий, папка (`/tree/...`), файл (`/blob/...`), `raw.githubusercontent.com`, архивы `/archive/...` и релизы.
- **Прямые ссылки** на `.json` / `.zip`.

Внутри архива поддерживаются обычные FNF-чарты (`notes` как массив), секции Psych/Vanilla с `sectionNotes`, и формат V-Slice/Polymod (`notes: {easy:[{d,t,l}], normal:[...]}`). Аудио `Inst` + `Voices` автоматически смешиваются в один трек и кодируются в MP3 (можно отключить — тогда будет WAV). Если аудио в моде нет (часто бывает у чарт-паков), его можно прикрепить вручную прямо в карточке песни.

**Большие моды (Indie Cross и т.п.).** Архивы на 500–750 МБ больше не грузятся целиком: инструмент находит CDN-зеркало GameBanana с поддержкой `Range`, читает только каталог ZIP и сами чарты (доли мегабайта), а аудио скачивает **только при нажатии «Скачать .osz»** для конкретной песни. Проверено на `gamebanana.com/mods/375741` (19 песен, 500 МБ) и `mods/562444` (22 песни, 730 МБ). Поэтому вставляй ссылку именно на страницу мода (`/mods/ID`), а не прямую `gamebanana.com/dl/ID` — для прямой ссылки инструмент не знает размер файла и вынужден качать его целиком.

Во время скачивания показывается процент, есть кнопка **«Отмена»**. Кнопка **«Скачать все песни одним архивом»** собирает один ZIP с `.osz` внутри каждой песни — так браузер не блокирует массовые загрузки.

Чарты и аудио не отправляются никуда (кроме загрузки по ссылке).

### Настройки

- **Тишина спереди, мс** — добавляет паузу в начало аудио и сдвигает все ноты на ту же величину. Даёт время на реакцию, синхронизация сохраняется. Аудио перекодируется в WAV (размер файла вырастает).
- **Клавиш (K)** — 4–18. Для 5K+ дорожки 4..7 считаются игровыми; для 4K это оппонент и он отбрасывается.
- **SV** — если больше 0, добавляется наследуемая timing-точка с `-100*SV` (скорость прокрутки).
- **Микс → MP3** — смешанное аудио кодируется в MP3 (~в 4 раза меньше, чем WAV).
- **alt-ноты → свисток** — альт-ноты FNF получают hitsound «whistle».
- **HP / OD** — подбери под себя; FNF-окна попадания ближе к высокому OD.

В `[Metadata]` записываются `Source` (ссылка на мод) и теги с доменом источника; Artist берётся из названия мода, Title — из названия песни.

## Поддерживаемые форматы чартов

- `song.notes` — плоский массив нот (Psych Engine и современные порты)
- `song.notes[].sectionNotes` — старый формат с секциями
- `song` / `data.notes` — массив нот напрямую
- поля времени: `songTime`, `noteTime`, `time`, `strumTime`, `startTime`
- дорожки: `noteData`, `lane`, `column`, `data`
- зажимы: `holdLength` / `sustainLength` / `length`, отдельные tail-ноты с `isSustainNote: true`, `noteType: HOLD_END`

BPM берётся из `song.bpm` либо из секций: при `changeBPM` создаётся несколько timing-точек. Ноты вне выбранного числа дорожек обрезаются с предупреждением.

## Как это устроено

`noteData (0..3)` → колонка mania (x = 0/128/256/384), `songTime` → время хит-объекта, зажимы → Long Note (`type 128`), BPM → `[TimingPoints]` (`beatLength = 60000 / bpm`). `.osz` собирается прямо в браузере собственным ZIP-писателем (метод STORE, без сжатия).

## Публикация (чтобы открывать с телефона)

Это статический сайт: достаточно загрузить `index.html` и `app.js` на любой хостинг. Самый простой вариант — **Cloudflare Pages → Direct Upload** (папка целиком), либо Worker со static assets. Сервер и база данных не нужны.

> Для публикации мапов с чужой музыкой нужны права обладателя; личное использование без проблем.

## Что дальше: Roblox / Project Afternight

Чарты Project Afternight не лежат обычными `.json` — они хранятся внутри движка игры в Lua-таблицах, а аудио — во внутренних ассетах Roblox. Поэтому «просто скачать чарт» не получится. реалистичные пути:

1. **Дамп таблиц из running-игры** — требует executor (`getgc`, `getGameFramework`), что нарушает ToS Roblox. Я не буду писать эксплойт-код, но могу помочь с обработчиком уже полученных данных.
2. **Запись авто-плейя** — если есть легальный способ получить лог нажатий (таймкоды + дорожка), такой лог можно превратить в чарт тем же конвертером (у меня уже есть наработки в папке проекта).
3. **Ручной ввод / импорт из community-чартов** — если сообщество выкладывает chart-файлы, достаточно адаптировать парсер под их формат.

Как только у тебя появится выгрузка чарта в любом читаемом виде (Lua-таблица, JSON, CSV таймкодов), я допишу парсер под неё и подключу к этому же интерфейсу как второй источник.
