FNF → osu!mania

Конвертер чартов браузерных FNF-игр в мапсеты osu!mania 4K. Работает прямо в браузере, на телефоне тоже.

1 Чарт и аудио

Нажми, чтобы выбрать файлы, или перетащи сюда
.json чарты + аудио (.mp3 / .ogg / .wav)

    ★ Импорт по ссылке

    Поддерживаются GameBanana, GitHub (repo, папка, blob, raw, archive) и прямые ссылки на .json / .zip. Чарты и аудио инструмент найдёт сам — искать руками .json не нужно.

    2 Информация о мапе

    Тишина спереди даёт время на реакцию: к аудио добавляется пауза, все ноты сдвигаются на столько же — синхронизация не ломается. Аудио при этом перекодируется в WAV (файл больше).

    3 Результат

    Чарт не покидает устройство (кроме загрузки по ссылке). Для публикации мапов с чужой музыкой нужны права.
